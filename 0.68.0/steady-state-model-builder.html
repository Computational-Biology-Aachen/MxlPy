    Steady-state models¶

    A SteadyStateModelBuilder describes a model without any dynamics: there are no variables, only parameters and quantities derived from them. This makes it a good fit for algebraic models, e.g. analytic steady-state solutions, response curves or allometric relationships.

    Because there is nothing to integrate, a SteadyStateModelBuilder is never simulated. Instead it is evaluated directly, which is both simpler and much faster.

    As an example we use an enzyme following Michaelis-Menten kinetics, which is competitively inhibited by \(I\)

    \[ v = \frac{V_{\max} \cdot S}{K_m \left(1 + \frac{I}{K_i}\right) + S} \qquad V_{\max} = k_{cat} \cdot E_{tot}\]

    Building the model¶

    Parameters and derived quantities work just like in the other builders. Parameters can also be initial assignments, and derived quantities can depend on each other in any order.

    In [2]:
    Copied! 
    def mul(a: float, b: float) -> float:
    return a * b


def apparent_km(km: float, i: float, ki: float) -> float:
    return km * (1 + i / ki)


def michaelis_menten(s: float, vmax: float, km: float) -> float:
    return vmax * s / (km + s)


def ratio(a: float, b: float) -> float:
    return a / b


def get_model() -> SteadyStateModelBuilder:
    return (
        SteadyStateModelBuilder()
        .add_parameters(
            {"kcat": 10.0, "e_tot": 0.5, "km": 2.0, "ki": 1.0, "S": 1.0, "I": 0.0}
        )
        .add_parameter("vmax", InitialAssignment(fn=mul, args=["kcat", "e_tot"]))
        .add_derived("km_app", fn=apparent_km, args=["km", "I", "ki"])
        .add_derived("v", fn=michaelis_menten, args=["S", "vmax", "km_app"])
        .add_derived("saturation", fn=ratio, args=["v", "vmax"])
    )

    Parameter scans¶

    scan.steady_state accepts a SteadyStateModelBuilder and evaluates it for every row of to_scan. It returns a SteadyStateScan holding one Evaluation per scanned value. Since there are no variables, the values are accessed via combined or get_args.

    Nothing is integrated, so there is no integrator to configure and no y0. Time course and protocol scans are not available for this builder.

    In [6]:
    Copied!

    get_model(),
    to_scan=pd.DataFrame({"S": np.geomspace(0.1, 100, 21)}),
)

    Fitting¶
    fit.steady_state accepts a SteadyStateModelBuilder and fits its parameters to a pandas.Series of data.
The data can contain any parameter or derived value.
    

    Here we assume we measured the rate \(v\) and the saturation of the enzyme at \(S = 2\) and fit \(K_m\) and \(k_{cat}\).

    Response coefficients¶
    Response coefficients describe how much the derived values change if a parameter is perturbed.
As the model is evaluated instead of simulated, these are just the (normalised) derivatives of evaluate().
For example, the rate \(v\) responds proportionally to \(k_{cat}\).

    Export¶
    SteadyStateModelBuilder models can be saved to the native .mxl.json format with mxlpy.save / mxlpy.load, and exported to MxlWeb, which evaluates them in the browser.

    import { SteadyStateModelBuilder } from "@computational-biology-aachen/mxlweb-core";
import { Add, Divide, Mul, Name, Num } from "@computational-biology-aachen/mxlweb-core/mathml";

export function initModel(): SteadyStateModelBuilder {
    return new SteadyStateModelBuilder()
      .addParameter("kcat", {
        value: 10.0,
        texName: 'kcat',
      })
      .addParameter("e_tot", {
        value: 0.5,
        texName: 'e\\_tot',
      })
      .addParameter("km", {
        value: 2.0,
        texName: 'km',
      })
      .addParameter("ki", {
        value: 1.0,
        texName: 'ki',
      })
      .addParameter("S", {
        value: 1.0,
        texName: 'S',
      })
      .addParameter("I", {
        value: 0.0,
        texName: 'I',
      })
      .addParameter("vmax", {
        value: new Mul([new Name("e_tot"), new Name("kcat")]),
        texName: 'vmax',
      })
      .addAssignment("km_app", {
        fn: new Mul([new Name("km"), new Add([new Num(1.0), new Divide([new Name("I"), new Name("ki")])])]),
        texName: 'km\\_app',
      })
      .addAssignment("v", {
        fn: new Divide([new Mul([new Name("S"), new Name("vmax")]), new Add([new Name("S"), new Name("km_app")])]),
        texName: 'v',
      })
      .addAssignment("saturation", {
        fn: new Divide([new Name("v"), new Name("vmax")]),
        texName: 'saturation',
      })
  }

    

    

    

    

    

    

    

    

    

    

    

    

    

    Current limitations¶
    The SteadyStateModelBuilder supports every routine whose question makes sense without dynamics: steady-state scans, fits (including group, ensemble and joint fits), Monte Carlo methods, response coefficients and sensitivity analysis.
Time courses, protocols and everything about reactions or fluxes don't apply to it.
