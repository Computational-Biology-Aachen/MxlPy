    Parameter sensitivities¶

    Global sensitivity analysis asks how much each parameter matters across a whole range of values. The complementary, local question is: how does every simulated value change when a parameter changes a little, right here? That is the derivative

    \[S_{ij}(t) = \frac{\partial y_i(t)}{\partial \theta_j}\]

    of every variable, derived quantity and reaction \(y_i\) with respect to every parameter (or initial value) \(\theta_j\). These forward sensitivities are what gradient-based fitting, Fisher-information analyses and identifiability checks are built on.

    MxlPy computes them by solving the sensitivity equations alongside the model,

    \[\frac{dS}{dt} = J\,S + \frac{\partial f}{\partial \theta}, \qquad S(0) = \frac{\partial x_0}{\partial \theta},\]

    where both the Jacobian \(J = \partial f / \partial x\) and \(\partial f / \partial \theta\) are generated symbolically from the model. This needs a single (larger) simulation instead of one extra simulation per parameter, and is as accurate as the integrator.

    Steady states¶

    At a steady state the sensitivities follow from the implicit function theorem, \(J\,\partial x^* / \partial \theta = -\partial f / \partial \theta\), without integrating anything. Conserved quantities make \(J\) singular; their totals are then fixed by the initial values, which MxlPy takes into account.

    When the model can't be differentiated symbolically¶

    Forward sensitivities need every rate function to be convertible to sympy. Models with e.g. neural-network surrogates or functions that can't be parsed automatically fall back to central finite differences (two extra simulations per parameter) and log a warning. You can also choose explicitly with method="forward" or method="finite_difference".

    Finite differences are only as accurate as the integrator allows: a too small step amplifies the integration error. The default relative step displacement=1e-3 suits the default tolerances of 1e-8.

    Explicit initial values, outputs and runners¶

    Pass explicit initial values or select only some outputs:

    forward_sensitivities.time_course(model, time_points, ["k1"], y0={"x": 1.0, "y": 0.0}, outputs=["v1"])

    When y0 isn't given, the initial values are taken from the model, so initial assignments depending on the parameters are differentiated as well.

    Runners provide the same with their own integrator and steady-state settings, which is where fits get their derivatives from:

    runner = KineticRunner(derivatives="auto", displacement=1e-3)
runner.time_course_sensitivities(model, time_points, ["k1"])
runner.steady_state_sensitivities(model, ["kf"])

    !!! note The Native and Diffrax integrators compile the model themselves and use finite-difference sensitivities.

    For the gradient of a loss with many parameters, adjoint gradients are much cheaper: one forward and one backward solve, whatever the number of parameters.
