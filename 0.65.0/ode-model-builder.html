    ODE models¶

    mxlpy has three model builders, which differ in how the right hand side of the system is written down:

    Builder Right hand side Typical use
    KineticModelBuilder (Model) \(N \cdot v(x)\): reactions with rate laws and a stoichiometric matrix metabolic & signalling networks
    OdeModelBuilder \(\frac{dx}{dt} = f(x)\): one differential equation per variable phenomenological models, equations taken from a paper
    SteadyStateModelBuilder no variables, only explicit functions of parameters algebraic / steady-state models, see Steady-state models

    This notebook covers the OdeModelBuilder. Use it when your model is naturally written as differential equations rather than as a reaction network. Since there are no reactions, an OdeModelBuilder has no fluxes and no stoichiometries.

    As an example we use logistic growth with a constant harvesting rate \(h\)

    \[\frac{dx}{dt} = r x \left(1 - \frac{x}{K}\right) - h x\]

    which has the non-trivial steady state \(x^* = K \left(1 - \frac{h}{r}\right)\).

    Building the model¶

    Instead of add_reaction, every variable gets exactly one differential equation via add_diff_eq, which also sets the variable's initial value. Parameters and derived quantities work just like in the KineticModelBuilder.

    As with all builders, use named functions instead of lambdas (they need to be inspectable and pickle-able).

    def logistic_harvest(x: float, r: float, capacity: float, h: float) -> float:
    return r * x * (1 - x / capacity) - h * x


def fraction(x: float, capacity: float) -> float:
    return x / capacity


def get_model() -> OdeModelBuilder:
    return (
        OdeModelBuilder()
        .add_parameters({"r": 1.0, "capacity": 10.0, "h": 0.2})
        .add_diff_eq(
            "x",
            fn=logistic_harvest,
            args=["x", "r", "capacity", "h"],
            initial_value=0.5,
        )
        .add_derived("saturation", fn=fraction, args=["x", "capacity"])
    )

    Simulation¶

    An OdeModelBuilder is simulated with the same Simulator as a KineticModelBuilder. The result is an OdeSimulation, which offers the same access patterns as a Simulation, minus everything flux related.

    Routines like scans and fits configure the simulation with an OdeRunner instead, see the integrator configuration.

    Response coefficients¶
    Response coefficients describe how much the steady state changes if a parameter is perturbed.
For an OdeModelBuilder they are available for the variables.
With the default normalisation, the steady state \(x^* = K (1 - h / r)\) responds proportionally to the carrying capacity \(K\).

    import { OdeModelBuilder } from "@computational-biology-aachen/mxlweb-core";
import { Add, Divide, Minus, Mul, Name, Num } from "@computational-biology-aachen/mxlweb-core/mathml";

export function initModel(): OdeModelBuilder {
    return new OdeModelBuilder()
      .addParameter("r", {
        value: 1.0,
        texName: 'r',
      })
      .addParameter("capacity", {
        value: 10.0,
        texName: 'capacity',
      })
      .addParameter("h", {
        value: 0.2,
        texName: 'h',
      })
      .addVariable("x", {
        value: 0.5,
        texName: 'x',
      })
      .addAssignment("saturation", {
        fn: new Divide([new Name("x"), new Name("capacity")]),
        texName: 'saturation',
      })
      .setDifferential("x", new Add([new Minus([new Mul([new Name("h"), new Name("x")])]), new Mul([new Name("r"), new Name("x"), new Add([new Num(1.0), new Minus([new Divide([new Name("x"), new Name("capacity")])])])])]))
  }

    

    

    

    

    

    

    

    

    

    

    

    

    

    Current limitations¶
    Everything about reactions, fluxes or stoichiometries only applies to the KineticModelBuilder.
Not supported for the OdeModelBuilder are thus
    

      

    • flux elasticities and rate characteristics in mca, reaction carousels, model comparisons and label models
      • 

    • Jacobians (Simulator(..., use_jacobian=True) falls back to finite differences with a warning) and events
      •
